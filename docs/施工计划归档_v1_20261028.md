## 3. 硬约束（施工期不得违反）

1. **四组新题必须接入现有 SRS**，不得另建孤立系统。
   - 七档间隔 `[1,2,4,7,15,30,60]`
   - 错题前置
   - 掌握度红黄绿
   - 记得=4 升档；模糊=3 档位不变仅重置 due_date；忘了=1/2 降档下限 0
   - `reviewGraduatedStage=7` 毕业置空 due_date
2. **prompt_drills 不接 AI**，纯本地自评，零成本零 Key。
3. **code_review 素材用本项目真实代码**，不编造。
4. **注释与实际不符时以代码为准**：`qa_page.dart:9` 的「本轮未实现 P1 四模块」为过时注释，实际四模块已在 `qa_extra_page.dart` 实现（`_ConceptQuizView` / `_SpotCheckView` / `_WhiteboardView` / `_ListeningView`）。
5. **终端操作铁律**：关键数字用 `python3 -c "print(...)"` 二次核对；不用 heredoc 传长内容（会丢行）；本机无 root，app 私有库不可读；`aapt/aapt2` 在 arm64 上 SIGILL，APK 校验走 Python `zipfile` + `utf-16-le`。
6. **git 提交粒度**：一任务一 commit，原子提交。
